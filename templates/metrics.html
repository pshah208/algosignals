Scoring Metrics

Each factor returns a score from -1.0 (bearish) to +1.0 (bullish). A value near 0.0 is often valid and means neutral/mixed/sparse data, not an error.

Composite Score & Actions
  • Technical {{ (weights.technical * 100)|int }}% + News {{ (weights.news * 100)|int }}% + Events {{ (weights.events * 100)|int }}% + Financials {{ (weights.financials * 100)|int }}% + Earnings {{ (weights.earnings * 100)|int }}%.
  • BUY when score ≥ {{ "%.2f"|format(buy_threshold) }}.
  • SELL when score ≤ {{ "%.2f"|format(sell_threshold) }}.
  • HOLD otherwise.

Data source: yfinance OHLCV history. Uses 20/50 SMA crossover, RSI-14, 20-day momentum, and ATR volatility. +1.0 means broad bullish technical setup, -1.0 means broad bearish setup, 0.0 means mixed/sideways or insufficient trend signal.

Data sources: Google News RSS by default (no API key required), optional NewsAPI supplement. Headlines are scored by LLM when enabled, otherwise VADER (and then lexicon fallback if VADER is unavailable). +1.0 = strongly positive headline tone, -1.0 = strongly negative, 0.0 = neutral/mixed headlines or sparse headline data. NewsAPI key is optional.

Data source: yfinance dividends, splits, and calendar dates. Positive moves include dividend-paying/growing and bullish split signals; negatives include dividend cuts and reverse splits. 0.0 is common and legitimate when there are no recent dividends/splits and no earnings event in the near scoring window.

Data source: yfinance fundamentals (P/E, revenue growth, profit margin, debt/equity). +1.0 indicates strong growth/profitability with reasonable valuation/leverage, -1.0 indicates weak fundamentals, 0.0 means balanced or missing fundamental inputs.

Data source: yfinance earnings history/calendar. Uses EPS surprise, forward EPS growth signal, and upcoming-earnings proximity. +1.0 means strong earnings momentum, -1.0 means weak/negative earnings trend, 0.0 means neutral/mixed data or no strong earnings catalyst.
